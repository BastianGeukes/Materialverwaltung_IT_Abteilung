## Zusammenarbeit

Änderungen werden über eigene Branches und Pull Requests in `main` übernommen.

1. **Aktuellen Stand holen:** Auf `main` wechseln und die neuesten Änderungen von GitHub abrufen.
2. **Branch erstellen:** Für jede Aufgabe einen eigenen Branch von `main` anlegen, beispielsweise `feature/ArtikelServiceAnpassung`.
3. **Aufgabe bearbeiten:** Änderungen umsetzen, prüfen und mit Commit-Nachrichten speichern.
4. **Branch pushen:** Die Commits auf den eigenen Branch bei GitHub hochladen.
5. **Pull Request öffnen:** Als Zielbranch `main` auswählen und review anfordern.
6. **Review durchführen:** Mindestens ein anderes Teammitglied muss zustimmen. Falls Rückmeldungen kommen diese bearbeiten und offene Diskussionen abschließen. Nach neuen Änderungen ist eine erneute Freigabe erforderlich.
7. **Merge durchführen:** Den freigegebenen Pull Request über „Squash and merge“ übernehmen und den erledigten Feature-Branch löschen.
8. **Für die nächste Aufgabe:** Lokal wieder auf `main` wechseln, aktualisieren und einen neuen Feature Branch erstellen.
